## Description

> **Phase:** Foundation (Task 01 of 05) · **Depends on:** #1 (Task 00) · **Rule:** every task leaves the repo bootable.

**Goal:** A browser request travels through K8s Ingress to the frontend, the frontend makes an API call through the same Ingress to the Core API, and the result is displayed. Proves the network plumbing works.

## What to build

| Component | What changes |
|---|---|
| Core API | Add `GET /api/health` → `{ "status": "ok", "timestamp": "...", "version": "0.1.0" }`. Configure CORS to allow frontend origin. |
| Frontend | Install React Router. App shell layout: NavBar (logo + Dashboard/Expenses/Settings + avatar placeholder), main content area, dark theme CSS variables. 3 routes: `/dashboard`, `/expenses`, `/settings` — placeholder pages. On `/dashboard` mount, fetch `/api/health` and display connection status. |
| K8s Ingress | Traefik IngressRoute: `/api/*` → core-api Service, `/*` → frontend Service. TLS not required locally. |

## NOT in scope

No auth, no database, no real data. NavBar links work (client-side routing), but pages are empty placeholders with "Coming soon" text.
